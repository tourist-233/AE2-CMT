# AE2 CMT — 元件管理终端

[![Minecraft](https://img.shields.io/badge/Minecraft-1.21.1-62b47a.svg)](https://www.minecraft.net/)
[![NeoForge](https://img.shields.io/badge/NeoForge-21.1.240%2B-e8a33d.svg)](https://neoforged.net/)
[![AE2](https://img.shields.io/badge/Applied%20Energistics%202-19.2.17%2B-8a4bd6.svg)](https://github.com/AppliedEnergistics/Applied-Energistics-2)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**AE2 CMT**（Component Management Terminal，元件管理终端）是一个 Applied Energistics 2 附属模组。它让玩家**不用跑到驱动器面前**，就能远程查看并整理整张 ME 网络里所有 ME 驱动器中的存储元件。

终端有两种形态，功能完全一致：

| 形态 | 物品 ID | 说明 |
| --- | --- | --- |
| **无线元件管理终端** | `cmt:wireless_component_management_terminal` | 手持式。需要绑定到无线访问点，消耗 AE 能量（可插能源卡扩容） |
| **ME元件管理终端** | `cmt:component_management_terminal` | 线缆部件。贴在 ME 线缆上使用，需要占用一个频道；权限跟随 AE2 的网络安全设置 |

---

## 功能

### 驱动器远程管理

打开终端后会列出**所连 ME 网络内所有 ME 驱动器**（不论它在世界的哪个角落），每个驱动器显示：

* 名称（自定义名或方块名）与其方块图标
* 该驱动器的每个元件槽位，槽位中显示真实的元件及其当前状态
* 每个元件的**占用率进度条**，悬停可看到「已用 / 总量」与「存储类型数」的明细

对元件的所有操作都是**直接作用于真实驱动器**的，不需要先把驱动器挂载到终端上：

* 插入元件、取出元件、槽位之间拖动交换
* 插入 / 取出会**即时**被 ME 网络识别或断开

### 分页与分组

* 界面按**内容行**滚动（一个驱动器占「名称行 + 若干元件行」），窗口高度随内容伸缩
* 元件槽位池共 **128 格**（每行 10 格），单屏最多 24 行内容
* 驱动器超过窗口容量时自动分页，滚动条只显示在当前窗口内的驱动器

### 网络存储总览

物品栏两侧有两条**竖向进度凹槽**，随界面实时刷新：

* 左：全网**存储类型**占用（已用类型数 / 可用类型容量）
* 右：全网**存储容量**占用（已用字节 / 总字节）

容量数字统一保留一位小数（如 `524.3k`）。

### 无限存储识别

模组会识别两类"无限"并分别处理：

* **容量真无限**（AE2 的无限容量元件、NeoECO 集群的无限模式）→ 两条进度条**拉满并变紫**
* **资源无限但容量正常**（如无限水/圆石元件、NeoECO 无限资源供应矩阵）→ 只让该元件的容量条变紫，不会污染全网统计

悬停无限元件时显示「存储类型：无限 / 存储量：无限」。

### 排序与搜索（服务端已具备）

服务端实现了按**位置 / 名称 / 已用率**排序，以及按**驱动器名 / 坐标 / 元件名**过滤。客户端的界面控件尚未提供，因此当前版本还无法在界面上操作（详见[已知限制](#已知限制)）。

### 权限与安全

无线终端支持"归属"概念：**第一个打开它的玩家成为它的主人**，此后的使用受服务端配置约束（`SELF` / `TEAM` / `ALL`）。线缆部件则**不引入额外归属数据**，直接跟随 AE2 自己的网络安全机制。

## 支持的驱动器

| 来源 | 类型 | 支持情况 |
| --- | --- | --- |
| **AE2 本体** | ME 驱动器（`DriveBlockEntity`，10 槽） | 完整支持 |
| **NeoECO AE Extension** | **LD 存储矩阵驱动器**（多方块集群，每方块 1 槽） | 支持，并会按集群合并成一条记录 |
| NeoECO AE Extension | CD 晶阵驱动器（计算用） | 不显示（不是存储宿主） |
| 其它附属模组的元件宿主 | — | 不在管理范围内 |

NeoECO 是**可选**模组：未安装时该部分代码不产生任何影响；安装后通过反射桥接读取其元件与容量，无需编译期依赖。

## 界面

* 界面材质为 `assets/ae2/textures/guis/cmt_interface.png`
* 面板由「标题栏 / 内容行 / 收边 / 玩家物品栏 / 底边」拼接而成，高度随内容行数伸缩，行为与 AE2 原生终端一致
* 无线终端右上角有 **4 个升级卡槽**（能源卡可提升能量上限）；线缆部件没有升级槽（与 AE2 终端部件一致）
* 中英双语（`zh_cn` / `en_us`）

## 依赖

必需：

* Minecraft **1.21.1**
* NeoForge **21.1.240** 或更高
* Applied Energistics 2 **19.2.17** 或更高

可选：

* [AE2WTlib](https://github.com/Mari023/AE2WirelessTerminalLibrary) **19.5.1** 或更高 —— 安装后无线终端会出现在通用终端（Universal Terminal）的终端列表里，并注册一个打开快捷键；该模组的 API 已通过 jarJar 内嵌，因此**不装它也能正常运行**，只是没有通用终端集成。

## 安装

1. 安装 NeoForge 21.1.240+ 的 Minecraft 1.21.1
2. 把 AE2、本模组的 jar 放入 `mods/` 目录（可选放入 AE2WTlib）
3. 启动游戏即可 —— 两个终端物品都出现在 **AE2 的创造模式物品页**里

---

## 使用

1. **无线版**：先把它绑定到无线访问点（与 AE2 无线终端的方式相同），再手持右键打开；未绑定、超出范围或没电时界面会提示原因。
2. **部件版**：贴在 ME 线缆上（会占一个频道），右键打开。
3. 界面里可查看所有驱动器的元件、插入/取出/拖动交换元件，滚轮浏览分页内容。
4. 悬停元件的容量条可以看详细的已用/总量与类型数；物品栏两侧的凹槽给出全网总览。

## 配置

服务端配置（`config/cmt-server.toml`）：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `allowExtract` | `true` | 是否允许通过终端**取出**元件 |
| `allowInsert` | `true` | 是否允许通过终端**插入**元件 |
| `permission` | `SELF` | 谁可以使用他人的终端：`SELF` 仅主人 / `TEAM` 主人所在计分板队伍 / `ALL` 任何人 |
| `scanIntervalTicks` | `10` | 终端打开时重新扫描网络的间隔（tick，1–200）。网络很大时可以调大以降低开销 |

## 构建

```bash
./gradlew build          # 产物在 build/libs/cmt-<version>.jar
./gradlew runClient      # 开发环境启动客户端
./gradlew runServer      # 开发环境启动服务端
```

需要 JDK 21。

## 已知限制

* **排序 / 搜索暂无界面入口**：服务端逻辑完整，客户端尚未提供控件，属于未完成的半成品功能。
* **通用终端内的集成不完整**：从 AE2WTlib 通用终端切到本终端时，缺少终端选择面板与 WUT 热键支持，也看不到量子纠缠奇点槽（独立使用物品时不受影响）。
* **扫描开销恒定**：终端打开期间每 `scanIntervalTicks` 会重扫一次网络并发一次快照，即使内容没有变化；超大网络建议调大该间隔。
* **仅管理驱动器**：存储总线、元件工作台等其它元件宿主不在管理范围内。
